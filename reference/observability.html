L08 Observability & Cost

冇 measure 就冇 improve。LLM 系統要 monitor 嘅嘢比一般 API 多。

面試官真正想問嘅嘢 生產環境現實 解決思路 現實例子 + code

面試官真正想問嘅嘢

  • 考 production ownership：你上線之後點知佢健唔健康？
  • 考成本控制：LLM 成本可以好快失控

🗣️ 示範答法（30 秒版）

「我會監控四類指標：latency（TTFT、p95）、reliability（錯誤率、429、fallback 率）、cost（按 feature 同 tenant）、quality（validation failure、用戶 feedback、eval 分數）。每個 LLM call 都有 trace span，記錄 model、tokens 同 finish reason，一個用戶 request 嘅多次 call 用同一個 trace 串埋。成本有即時 dashboard 同異常 alert，agent 類功能一定有 max steps 同 token budget。」

生產環境現實

情境：一個 agent 功能因為 bug 陷入 tool-call loop，單一 request 不停 call LLM，直到有人睇 billing 先發現。

處理：每個 request 設 max LLM calls / max tokens budget；按 feature 做成本 dashboard 同 alert（例如每小時成本異常上升）；trace 入面顯示每一步 call。

解決思路

建議監控嘅指標：

  • Latency：TTFT、總時間、tokens/sec（p50 / p95 / p99）
  • Reliability：錯誤率（按 provider / status code）、429 比率、fallback 觸發率、stream 中斷率
  • Cost：每個 request、每個 feature、每個 tenant 嘅 token 同成本
  • Quality：structured output validation failure rate、用戶 feedback（👍/👎）、eval 分數、RAG「搵唔到」比率
  • Tracing：一個用戶 request 可能觸發多次 LLM call（RAG、tool call、agent loop），要用 trace ID 串埋

⚠️ 常見陷阱

  • 淨係睇平均 latency，唔睇 p95 / p99 同 TTFT
  • 成本只喺月尾 billing 先睇到，冇即時 alert
  • Log 冇 feature / tenant 維度，唔知錢用咗喺邊
  • Agent loop 冇 max steps / token budget

現實例子 + code

Python · tracing + loop budget
# OpenTelemetry 風格：為每次 LLM call 加 span 同屬性
from opentelemetry import trace
tracer = trace.get_tracer("llm")

def traced_llm_call(client, feature: str, **kwargs):
    with tracer.start_as_current_span("llm.chat") as span:
        span.set_attribute("llm.model", kwargs.get("model", ""))
        span.set_attribute("app.feature", feature)
        resp = client.chat.completions.create(**kwargs)
        if resp.usage:
            span.set_attribute("llm.prompt_tokens", resp.usage.prompt_tokens)
            span.set_attribute("llm.completion_tokens", resp.usage.completion_tokens)
        span.set_attribute("llm.finish_reason", resp.choices[0].finish_reason or "")
        return resp

# Agent / tool loop 安全閥
MAX_STEPS = 8
for step in range(MAX_STEPS):
    ...  # call model, run tool
else:
    raise RuntimeError("Agent exceeded max steps")
